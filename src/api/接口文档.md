## POST 审核退款申请（临时前端测试接口）

POST /api/refund/audit

**临时测试接口**，用于前端测试退款审核流程。正式版本会移至后台管理系统。

### 审核流程说明
1. **申请提交**: 用户提交退款申请，状态为"待审核"，余额被冻结
2. **审核处理**: 管理员进行审核，可以通过或拒绝
3. **审核通过**: 从冻结余额中扣减，调用第三方退款API，状态变为"退款完成"
4. **审核拒绝**: 解冻余额，状态变为"审核拒绝"

### 限制说明
- 每个学生同时只能有一个待审核的退款申请
- 只有"待审核"状态的申请才能被审核
- 审核后状态不可逆转
