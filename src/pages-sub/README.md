# pages-sub 目录结构

```
pages-sub/
├── balance/                    # 余额模块
│   ├── home/                   # 余额查询
│   ├── recharge/               # 账户充值
│   ├── history/                # 充值记录
│   ├── result/                 # 充值结果
│   └── refund/                 # 余额退款
│       ├── apply/              # 申请退费
│       ├── history/            # 退款记录
│       └── result/             # 退款结果
│
├── package/                    # 套餐模块
│   ├── list/                   # 套餐列表
│   ├── detail/                 # 套餐详情
│   ├── history/                # 购买记录
│   ├── result/                 # 操作结果
│   └── refund/                 # 套餐退款
│       ├── history/            # 退款记录
│       └── detail/             # 退款详情
│
├── consumption/                # 消费模块
│   └── history/                # 消费记录
│
├── fund/                       # 资金模块
│   ├── balance/                # 余额查询
│   └── history/                # 资金流水
│
├── parent/                     # 学生管理
│   └── student/
│       ├── bind/               # 绑定学生
│       └── detail/             # 学生信息
│
├── family/                     # 亲情号
│   ├── manage/                 # 亲情号管理
│   └── edit/                   # 编辑亲情号
│
├── device/                     # 设备模块
│   └── subscribe/              # 设备订阅
│
├── profile/                    # 个人资料
│   └── edit/                   # 编辑资料
│
├── chat/                       # 聊天/留言
│
├── common/                     # 公共页面
│   ├── role-switch/            # 切换身份
│   ├── signature/              # 签名
│   ├── follow/                 # 关注公众号
│   ├── icon/                   # 图标展示
│   └── webview/                # 网页容器
│
├── service/                    # 服务协议
│   ├── privacy/                # 隐私政策
│   ├── protocol/               # 用户协议
│   └── purchase/               # 购买协议
│
└── demo/                       # 演示页面
    └── login-test/             # 登录测试
```
